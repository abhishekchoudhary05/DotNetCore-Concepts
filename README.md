# DotNetCore-Concepts

A small demonstration repository showcasing concepts and examples for .NET 10 (DotNetCore) projects. This solution contains sample code and minimal examples intended for learning and experimentation.

## Requirements

- .NET 10 SDK (install from https://dotnet.microsoft.com)
- Visual Studio 2026 or later (optional) or any editor that supports .NET

## Build and run

1. Open a terminal in the repository root (where DotNetCore-Concepts.slnx is located).
2. Restore and build the solution:

   dotnet restore
   dotnet build

3. To run the example console project (if present):

   dotnet run --project DotNetCore-Concepts

Adjust the project path if you have more than one project or a different startup project.

## Solution structure

- DotNetCore-Concepts.slnx — Solution file
- DotNetCore-Concepts/ — Main project directory (console/web/other projects)

Explore the Program.cs and project files for concrete examples and notes.
